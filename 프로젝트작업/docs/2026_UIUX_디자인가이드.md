# 2026 UI/UX 디자인 가이드 — FORMA 쇼핑몰

이 문서는 `02/` 웹 쇼핑몰 프로젝트의 **화면·스타일·컴포넌트 기준**이다.  
이전 시안(인디고 CTA · 필 칩 · 테두리 카드 · 플레이스홀더 박스)은 **폐기**하고, 이 문서와 [`시안/`](./시안/) HTML·PNG를 따른다.

- 브랜드: **FORMA** (포마) — 라이프스타일 셀렉트숍
- 대상 스택: React 19 + CRA + 순수 CSS(CSS 변수)
- 토큰/시안 CSS: [`시안_토큰.css`](./시안_토큰.css)
- 시안: [`시안/`](./시안/) HTML 원본 + PNG
- 상위 규칙: [`../02RULE.md`](../02RULE.md)

## 0. 왜 전면 수정했는가

| 이전 (폐기) | 2026 FORMA |
|---|---|
| 인디고 `#4F46E5` 템플릿 액센트 | 제이드 잉크 `#0B5F66` — 신뢰·차분 |
| 흰 바탕 + 둥근 카드 + 필 필터 | 스톤 페이퍼 바탕 + **풀블리드 히어로** + **벤토** |

| 다크모드를 메인 시안으로 강조 | 라이트 우선, 다크는 토큰 교체만 |
| Inter/Roboto/시스템 느낌 | Display **Syne** + 본문 **Pretendard** |

## 1. 브랜드 · 비주얼 디렉션

### 한 줄
> **상품이 무대, UI는 조명.** 장식·칩·뱃지 과다 금지. 첫 화면은 브랜드와 한 장의 장면으로 읽혀야 한다.

### 브랜드 테스트
네비를 가려도 **FORMA**와 히어로 장면이 남으면 통과.  
네비를 가리면 아무 쇼핑몰이나 되면 실패 → 브랜드·타이포·히어로를 키운다.

### 2026 원칙 (쇼핑몰)

| # | 원칙 | 적용 |
|---|------|------|
| 1 | **풀블리드 히어로** | 홈 첫 뷰포트 = 가장자리까지 이미지/장면. 인셋 카드형 배너 금지 |
| 2 | **히어로 예산** | 첫 화면: 브랜드 · 한 줄 헤드 · 짧은 문장 · CTA 묶음 · 지배 이미지. 통계·일정·프로모 칩 금지 |
| 3 | **벤토로 탐색** | 추천·컬렉션은 동일 크기 그리드가 아니라 **크기·역할이 다른 모듈** |
| 4 | **카드는 상호작용에만** | 상품 목록은 기본적으로 **보더리스**. 장바구니 요약·옵션 패널처럼 조작 단위만 면(surface) |
| 5 | **택타일 마이크로모션** | hover 이미지 스케일, CTA press, 스크롤 fade — 과한 glow/그림자 금지 |
| 6 | **신뢰 아키텍처** | 배송·반품·재고를 구매 CTA 근처에 짧게. 배너 스티커로 올리지 않음 |
| 7 | **모바일 엄지 존** | 상세 sticky ATC, 하단 핵심 액션 |
| 8 | **성능이 디자인의 일부** | 3초 이내 LCP 목표. 자동 회전 캐러셀 금지 |

### 쓰지 말 것 (안티패턴)

- 보라/인디고 그라데이션 테마, 네온 glow, 이모지 UI
- 필(pill) 카테고리 칩 나열을 홈 1뎁스에 두기
- 히어로 위 플로팅 뱃지·스티커·프로모 칩
- 크림 `#F4F1EA` + 세리프 + 테라코타 조합(흔한 AI 룩)
- 다크모드를 기본 시안으로 제시

## 2. 컬러 토큰

컴포넌트에 hex를 직접 쓰지 않는다. **아래 변수만** 사용한다.

```css
:root {
  /* 면 */
  --color-bg:            #F2F3F5;   /* 스톤 페이퍼 — 순백 대신 */
  --color-surface:       #FFFFFF;
  --color-surface-sunken:#E8EAED;
  --color-border:        #D6D9DE;
  --color-border-strong: #B8BDC6;

  /* 텍스트 */
  --color-ink:           #12141A;
  --color-ink-soft:      #5C6370;
  --color-ink-faint:     #8B919C;
  --color-inverse:       #F7F8FA;

  /* 브랜드 / CTA */
  --color-brand:         #0B5F66;   /* 제이드 잉크 */
  --color-brand-hover:   #084A50;
  --color-brand-soft:    #E6F3F4;
  --color-accent:        #E24B3B;   /* 세일·긴급 — 브랜드와 분리 */

  /* 상태 */
  --color-success:       #1F7A4C;
  --color-warning:       #B86E00;
  --color-danger:        #C62828;
  --color-star:          #C98500;

  /* 히어로 오버레이 */
  --color-scrim:         rgba(18, 20, 26, 0.42);
}
```

### 다크 (선택 · `data-theme="dark"`)

라이트가 기본이다. 다크는 시스템/토글 시 토큰만 교체.

```css
[data-theme="dark"] {
  --color-bg:            #0E1014;
  --color-surface:       #171A21;
  --color-surface-sunken:#1F2430;
  --color-border:        #2A303C;
  --color-border-strong: #3A4250;
  --color-ink:           #F2F3F5;
  --color-ink-soft:      #A8AEB8;
  --color-ink-faint:     #7A8190;
  --color-inverse:       #12141A;
  --color-brand:         #3DB8C2;
  --color-brand-hover:   #5EC9D1;
  --color-brand-soft:    #143338;
  --color-accent:        #FF6B5C;
  --color-scrim:         rgba(0, 0, 0, 0.55);
}
```

### 색 규칙

| 규칙 | 내용 |
|---|---|
| Primary CTA | `--color-brand` 화면당 **강조 1개** |
| 할인가 | `--color-accent` (브랜드 청록과 역할 분리) |
| 배경 | 순백 `#FFF`를 페이지 통짜로 쓰지 않음 → `--color-bg` |
| 하드코딩 | `color: #333` 금지 → 토큰 |

## 3. 타이포그래피

```css
:root {
  --font-display: 'Syne', 'Pretendard', sans-serif;     /* 브랜드·히어로·가격 강조 */
  --font-sans:    'Pretendard', 'Noto Sans KR', sans-serif;

  --text-xs:   0.75rem;   /* 12 — 캡션만 */
  --text-sm:   0.875rem;  /* 14 — 보조 */
  --text-base: 1rem;      /* 16 — 본문 최소 */
  --text-lg:   1.125rem;  /* 18 — 상품명 */
  --text-xl:   1.5rem;    /* 24 — 섹션 */
  --text-2xl:  2rem;      /* 32 — 페이지 */
  --text-hero: clamp(2.5rem, 5vw, 4.5rem); /* 히어로 */

  --leading-tight:  1.15;
  --leading-snug:   1.35;
  --leading-body:   1.65;
  --tracking-display: -0.03em;
}
```

| 규칙 | 내용 |
|---|---|
| 브랜드 로고 | Display, weight 700–800, tracking tight. 네비 텍스트보다 **항상 큼** |
| 히어로 헤드 | `--text-hero`, 한 줄~두 줄. 헤드가 브랜드를 압도하면 안 됨 |
| 상품명 | 2줄 말줄임, `word-break: keep-all` |
| 가격 | Display 또는 sans 700, 상품명보다 한 단계 크게 |
| 본문 | 16px 미만 금지 (모바일 확대 방지) |

## 7. 컴포넌트 규격

### 7-1. 헤더

- 높이 `--header-h` (72). 스크롤 시 얇은 보더 + surface.
- 로고 **FORMA**가 히어로 아래에서도 식별 가능하게 크게.
- 검색은 필이 아닌 **밑줄/사각 인풋** 또는 아이콘 확장.
- 모바일: 로고 · 검색 · 장바구니. 카테고리는 드로어/하단.

### 7-2. 버튼

| 종류 | 용도 | 화면당 |
|---|---|---|
| **Primary** | 담기 · 주문 · 결제 | 강조 **1** |
| Secondary | 위시 · 계속 쇼핑 | 여러 개 |
| Ghost | 취소 · 닫기 | 여러 개 |
| Danger | 삭제 · 주문취소 | 확인 필수 |

```css
.btn {
  min-height: 48px;
  padding: 0 var(--space-5);
  border-radius: var(--radius-sm);   /* 필 금지 */
  font-family: var(--font-sans);
  font-size: var(--text-base);
  font-weight: 600;
  letter-spacing: -0.01em;
  transition: background .15s ease, transform .1s ease;
}
.btn-primary {
  background: var(--color-brand);
  color: var(--color-inverse);
  border: none;
}
.btn-primary:hover { background: var(--color-brand-hover); }
.btn-primary:active { transform: scale(.98); }
.btn:focus-visible {
  outline: 2px solid var(--color-brand);
  outline-offset: 3px;
}
```

### 7-3. 상품 타일 (보더리스)

구성: **이미지 → (선택) 작은 라벨 → 상품명 → 가격 → 별점**

```
┌─────────────────┐
│                 │  3:4 또는 1:1, object-fit: cover
│     이미지       │  배경 --color-surface-sunken (CLS 방지)
│                 │
├─────────────────┤  ← 보더·그림자 없음
│ SALE  31%       │  라벨은 텍스트형, 작은 사각
│ 라이트 다운 …    │  --text-lg
│ 129,000원       │  accent + 취소 정가
│ ★ 4.9  (452)    │
└─────────────────┘
```

- 카드 박스(보더+라디우스+배경)로 감싸지 않는다.
- 이미지만 `border-radius: var(--radius-md)`.

### 7-4. 가격

| 상황 | 표기 |
|---|---|
| 정가 | `15,900원` — ink, 굵게 |
| 할인 | `31%` + `129,000원`(accent) + `189,000`(취소, faint) |
| 품절 | `품절` — faint + 이미지 40% 오버레이 가능 |

천단위 콤마, 단위 `원`. `KRW`/`₩` 혼용 금지.  
`toLocaleString('ko-KR')`.

### 7-5. 입력

- 높이 48px, 본문 16px, 라벨 **항상 노출** (placeholder로 대체 금지).
- 오류: 필드 아래, `--color-danger`, 구체적 문구.

### 7-6. 수량 스테퍼

`[ − ]  2  [ + ]` — 각 컨트롤 44×44 이상. 1 미만 금지. 삭제는 별도 Ghost.

### 7-7. 라벨 (뱃지 대체)

필 뱃지 대신 **작은 사각 텍스트 라벨**.

| 라벨 | 스타일 |
|---|---|
| SALE | accent 배경 / inverse 글자 |
| NEW | brand-soft / brand 글자 |
| 품절 | sunken / faint |

## 8. 화면 구성

| 화면 | 첫 목표 | 주 CTA | 시안 |
|---|---|---|---|
| 홈 | 브랜드+시즌 장면 → 벤토 탐색 → 추천 | 쇼핑하기 / 상품 클릭 | `01_홈` |
| 상품 상세 | 큰 미디어 + 옵션 + 신뢰문구 | **장바구니 담기** (sticky) | `02_상품상세` |
| 장바구니 | 수량·금액 명확 | **주문하기** | `03_장바구니` |
| 결제 | 배송→결제 1페이지 스텝 | **결제하기** | `04_결제` |
| 주문 완료 | 주문번호·금액 확인 (스텝 3) | **쇼핑 계속하기** | FN `/order-complete` |
| 위시리스트 | 저장 상품 확인·담기 | **장바구니로** | FN `/wishlist` |
| 검색 결과 | 키워드로 상품 탐색 | **상품 둘러보기**(빈 결과) | FN `/search` |

### 홈 구조 (위→아래)

1. **풀블리드 히어로** (100vh 근처, scrim + FORMA + 헤드 + CTA)
2. **벤토 컬렉션** (시즌·카테고리 모듈)
3. **추천 상품** 보더리스 그리드
4. 푸터 (배송/CS — 히어로에 넣지 않음)

### 금액 요약

```
상품 금액          240,800원
배송비             +3,000원
할인              −5,000원     ← accent
────────────────────────────
결제 예정 금액     238,800원     ← display, 굵게
```

## 11. React 19 구현 규칙 (`02/FN`)

## 13. 구현 체크 (PR 전)

- [ ] 홈 첫 뷰포트가 풀블리드인가 (인셋 배너 아닌가)
- [ ] Primary 액센트가 제이드인가 (인디고/보라 아닌가)
- [ ] 상품 목록이 보더리스 타일인가
- [ ] 필 칩 카테고리 남용 없는가
- [ ] 히어로에 통계·프로모 스티커가 없는가
- [ ] 로딩/빈/오류 상태가 있는가
- [ ] 다크는 토큰만으로 동작하는가 (별도 hex 분기 없음)
